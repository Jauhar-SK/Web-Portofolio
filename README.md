# Web Portofolio Jauhar Al Fahri

Web portofolio bertema game untuk penugasan Ameliorer Informatika UNESA 2026.

## Isi
- About Me (nama, NIM, prodi, pendidikan, aktivitas) dan Lore
- Quest Log (pengalaman)
- What I Can Do (status, skill, tools)
- Achievement
- Gacha fakta tentang saya
- Deck project
- Kontak

## Teknologi
HTML, CSS, dan JavaScript (satu file, tanpa framework).

## Cara membuka
Buka file `index.html` di browser, atau lihat versi online di:
https://jauhar-sk.github.io/Web-Portofolio/
